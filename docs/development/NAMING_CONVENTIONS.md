# Naming Conventions

- **React Components:** PascalCase (e.g., `GovernmentHeaderZone.tsx`)
- **Blueprints:** PascalCase with `Blueprint` suffix (e.g., `VehiclePassBlueprint.ts`)
- **Types/Interfaces:** PascalCase (e.g., `GovernmentCredential`)
- **Configuration Files:** kebab-case (e.g., `document-tokens.ts`)
- **Providers:** PascalCase with `Provider` suffix (e.g., `BrowserPrintProvider.ts`)
- **Enums:** PascalCase for the Enum name, UPPER_SNAKE_CASE for values (e.g., `CredentialType.VEHICLE_PASS`).
