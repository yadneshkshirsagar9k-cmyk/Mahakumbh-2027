# Folder Structure Guidelines

When adding new files, adhere to the established domain boundaries:

- **New UI Block for a Document:** `components/credentials/zones/`
- **New Export Method (e.g. Email):** `components/credentials/export/providers/`
- **New Credential Layout:** `components/credentials/blueprints/`
- **New Business Rule:** `config/credential-specs.ts`
- **New Color/Spacing:** `config/document-tokens.ts`
- **New Data Model:** `types/`
