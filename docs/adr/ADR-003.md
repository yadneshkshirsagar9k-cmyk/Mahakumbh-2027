# ADR 003: Rendering before Exporting

## Status
Accepted

## Context
PDF generation libraries often require manual drawing (e.g., `doc.text(10, 20, 'Name')`), which duplicates layout logic already written in React/CSS.

## Decision
The Architecture strictly enforces that all Layouts are produced *only* by the React Rendering Engine. Exporters must consume the rendered DOM.

## Consequences
- **Positive:** 100% visual parity between the screen Preview and the physical Print/PDF.
- **Positive:** Only one set of layout code to maintain.
- **Negative:** Generating PDFs requires headless browsers or HTML-to-Canvas solutions, which can be heavier than direct PDF drawing.
