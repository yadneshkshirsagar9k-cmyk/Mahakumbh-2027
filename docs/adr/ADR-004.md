# ADR 004: Export Provider Adapter Pattern

## Status
Accepted

## Context
We needed to support standard printing now, but client-side PDF downloads and server-side PDF generation in the future.

## Decision
We implemented the `ExportProvider` interface. The `ExportEngine` prepares an `ExportJob` and dispatches it to whichever Provider is registered (currently `BrowserPrintProvider`).

## Consequences
- **Positive:** Adding a new export target does not touch the core engine.
- **Positive:** Future-proofs the architecture for backend integration.
