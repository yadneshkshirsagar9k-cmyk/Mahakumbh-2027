# ADR 002: Declarative Credential Blueprints

## Status
Accepted

## Context
Initially, different credentials (e.g., Vehicle Pass, ID Card) were built as separate monolithic React pages with hardcoded `if/else` logic to hide or show elements. This scaled poorly.

## Decision
We implemented `DeclarativeBlueprints`. Layouts are now defined as JSON-like arrays of `DocumentZoneType` objects with attached `visibilityRules`.

## Consequences
- **Positive:** Adding a new credential takes minutes and requires zero new React components.
- **Positive:** Complete separation of configuration from rendering logic.
- **Negative:** Increased complexity in the `ZoneResolver` engine.
