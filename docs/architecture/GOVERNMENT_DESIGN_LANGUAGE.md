# Government Design Language

The Government Design Language guarantees that every document generated by the platform carries a consistent, authoritative aesthetic. 

## 1. Design Tokens (`config/document-tokens.ts`)
The platform uses a strict token system, bypassing arbitrary CSS classes:
- **Primary Colors:** Deep Navy Blue (`#002B5B`), Saffron Accent (`#EA580C`).
- **Status Colors:** Deep Green for Verification, Dark Red for Emergencies.
- **Backgrounds:** Warm White (`#FAFAFA`) with Neutral Gray borders.
- **Security Colors:** Very Light Blue-Gray for watermarks.

## 2. Typography
Typography enforces visual hierarchy:
- High-tracking (`tracking-widest`), uppercase headers.
- Monospace fonts for reference numbers and hashes.
- Micro-typography (6pt-8pt) for form labels.

## 3. Government Zones
Documents are not built as monolithic pages; they are composed of isolated "Zones":
- `GovernmentHeaderZone`: Official emblems and document titles.
- `IdentityZone`: Citizen data and photographs.
- `SecurityZone`: High-contrast QR codes and validation instructions.
- `AuthorityZone`: Digital signatures and timestamps.

## 4. Security Layers
Documents utilize absolutely-positioned background layers:
- `WatermarkLayer`: Scaled, rotated, low-opacity text for photocopy protection.
- `SealLayer`: Authentic government stamp graphics.
- `DocumentBackgroundLayer`: Guilloché-like patterns for forgery deterrence.
